# Manuscript in the Springer Nature LaTeX template

Built on 2026-11-14 from the template in `../main/sn-article-template/` (sn-jnl.cls, Version 3.1, December 2024) and its
user manual, with the Nature Portfolio reference style (`sn-nature`). The text and every number come from the checked
Nature-format version in `../main/manuscript.tex` (2026-11-11), which is left unchanged.

**Left out on purpose (to be added by the authors):** author names and affiliations; all Declarations (funding, competing
interests, ethics, consent, data, materials and code availability, author contributions, use of large language models).
Markers: the comment `Authors and affiliations` after `\title`, and the comment `Declarations ...` after `\backmatter`.

## How the template rules were applied

- Template structure: title, abstract (192 words, no citations), keywords, Introduction, Results (six subsections),
  Discussion, references, Methods, `\backmatter` (Supplementary information), Extended Data in `appendices`.
- Nature Portfolio rules from section 2.2 of the user manual: no footnotes; references inside the .tex file; Methods after the
  main text and the reference list; tables and figures with their legends at the end of the file; Extended Data under the
  heading "Extended Data" and numbered Extended Data Fig. 1 and Extended Data Tables 1-7; reference numbering continues.
- Unnumbered headings (`\unnumbered`, as the template provides). Default fonts (Computer Modern); no custom fonts.
- Only one layout change to the class behaviour: `\brokenpenalty=500` in the preamble. The class forbids a page break after
  any hyphenated line, which left pages several lines short.
- One extra standard package in the SI only: `array` (ragged-right text in the narrow columns of Supplementary Tables 9-10).

The figures are drawn 131 mm wide (the class text width, 372 pt), so 7 pt text stays 7 pt on the page. They read the same
result files as `paper/scripts/make_figures.py` (the 180 mm package figures, unchanged). Changes compared with those:
Fig. 1 is 2 x 2 instead of 1 x 4; every figure has one legend that does not cover data; Fig. 3 has shorter row labels and
arrows where an R2 interval is cut off at -1.5; Extended Data Fig. 1 now has the legend that its caption refers to.

## Build

    python make_figures_sn.py          # only after a result changes
    python inline_references.py        # after a citation or references.bib changes
    python build.py                    # manuscript.pdf, supplementary.pdf, manuscript_review.pdf

Checked on 2026-11-14 with tectonic: no overfull boxes, no undefined references or citations in any of the three PDFs, every page
viewed. The remaining log messages are the class's own `Underfull \vbox ... while \output is active` (it sets
`\flushbottom`; the unmodified template example gives the same messages) and two slightly loose lines (badness 3312 in
Methods, Uncertainty quantification; 1189 in Supplementary Table 5).
